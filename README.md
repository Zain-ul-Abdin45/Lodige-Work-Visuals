# Talent Brand Dashboard - Demo

Illustrative version of the dashboard, built on synthetic data, for showing HR
stakeholders and Meta (as part of the API access review) what the production
dashboard will look like. No live accounts are read here.

## Run locally

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python generate_demo_data.py     # writes data/demo_kpis.csv
streamlit run app.py
```

## What's in it

- Four primary sources from the KPI framework: Website (GA4), LinkedIn,
  Facebook, Instagram - each broken into Awareness, Engagement, Outcome.
- An Audience section (LinkedIn seniority mix, Facebook/Instagram age and
  gender) - this is what the requested `read_insights` scope is actually for,
  so it's worth showing even before real access.
- Extension sources (JOIN, HubSpot, manual quality-of-applicant) shown as
  a labeled roadmap strip, not fake numbers, since there is no API contract
  for them yet.
- Data is generated by `generate_demo_data.py` into the same tidy schema
  the real ETL will use (`date | platform | entity | metric | value`), plus
  two small snapshot files for the audience breakdowns. Swapping in real
  exports later means pointing the app at different CSVs, not rebuilding it.

## Deploying for a few days

This is a Streamlit app, and Streamlit needs a persistent Python process -
it does not run on Vercel, which is built for static sites and serverless
functions. Options that need no code changes:

- **Streamlit Community Cloud** (streamlit.io/cloud) - free, made for this,
  deploy straight from a GitHub repo in a couple of minutes.
- **Hugging Face Spaces** - free, also a couple of minutes from a repo.
- **Render / Railway** - free or low-cost tier, a couple more steps.

Any of the three gets a shareable link within minutes. Take it down (or let
the free tier sleep) once the demo is no longer needed.
